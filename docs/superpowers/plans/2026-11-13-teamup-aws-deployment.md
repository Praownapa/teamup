# TeamUp AWS Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put TeamUp online in Tokyo (CloudFront → ALB → ECS Fargate, RDS PostgreSQL, Cognito, S3) with one deploy command, demo logins, a live smoke test, and reset and delete commands.

**Architecture:** There are three CloudFormation stacks:
- `network`: VPC, subnets and security groups.
- `data`: RDS and its secret, the cover bucket, Cognito and ECR.
- `app`: roles, logs, ECS services, the ALB, CloudFront and the bucket policy.

Bash scripts in `infra/` deploy them through the AWS CLI with the `teamup` profile. Small standard-library Python helpers parse the demo users and run the smoke test. pytest checks the templates' security and naming rules offline.

**Tech Stack:** AWS CloudFormation (YAML), AWS CLI v2, bash (Git Bash on Windows), Docker Desktop (linux/amd64 images), Python 3.12 with pytest, cfn-lint and PyYAML in `infra/.venv`, and the existing FastAPI backend (psycopg 3, boto3).

**Spec:** `docs/superpowers/specs/2026-11-13-teamup-aws-deployment-design.md`

## Review Focus

1. **The `aws login` session expires in the middle of a run.** Scripts stop with `AWS sign-in expired or wrong account: run "aws login --profile teamup" in PowerShell, then re-run.` A re-run continues cleanly: empty change sets succeed and existing demo users are left alone. Tests: Task 3 Step 6 (message) and Task 6 Step 7 (re-run).
2. **Browser uploads to a bucket created the same day.** Presigned URLs must use `<bucket>.s3.ap-northeast-1.amazonaws.com`. The global host redirects for up to a day, and browsers refuse redirects on CORS requests. Tests: Task 1 Step 1 (unit) and Task 7 check 12 (live PUT through the presigned URL).
3. **CloudFront drops `Authorization` or query strings on `/api/*`, or caches API answers or errors.** Tests: Task 7 checks 6–11, which include an unauthenticated 401 and then an authenticated 200 on the same path, and a `?q=` search.
4. **A redeploy serves stale `index.html` or `config.js`.** Test: Task 7 check 4, a repeat fetch must not be `X-Cache: Hit from cloudfront`.
5. **Role and status rules in Cognito mode.** John must stay admin through the `admin` group, and Jack must get 403 "Your account has been suspended.". Tests: Task 7 checks 10 and 11.
